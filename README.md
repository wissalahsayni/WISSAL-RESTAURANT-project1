# WISSAL Restaurant 🍽️

A restaurant website homepage built with HTML and CSS as part of my front-end development learning journey.

## ✨ Features

- Restaurant homepage
- Navigation bar
- Restaurant logo
- Background image
- Call-to-action buttons
- Custom CSS styling
- Hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## 📂 Project Structure

```text
wissal-restaurant/
├── index.html
├── style.css
├── images/
└── README.md
```

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## 🎯 Project Goal

Practice HTML page structure, CSS styling, Flexbox, background images, and navigation by building a restaurant homepage.
